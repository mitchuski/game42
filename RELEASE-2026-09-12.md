# Game of 42 — local first-release candidate

The survey recommendations were accepted on 12 September 2026. This checkout implements the first public-experience slice of that direction. It is prepared locally, not deployed.

## What is implemented

- A new editorial landing page: purpose → practice → carry, with the six-axis Star illustration, Emergence Spell, preserved view routes and current ecosystem entry points.
- One local practice task across Home, Flower and Map: scope, source, role, resource boundary, artefact, review, revision history, selected reading, full backup and restore. Reviewing a task lights one practice station on its selected axis. This is a visual marker, not a credential.
- Persistent practice labelling, including mobile Territory. Demo lifecycle events and completed boards no longer present themselves as real verified contributions.
- Removal of Grid’s hash-prefix “common ground” links. Gold links are labelled declared prior references; they are not signature-verified relationships.
- Atomic Territory replay validation: every event must be legal, verification events must carry a syntactically valid content label, and a claimed group seal must match the replay and geometry. These checks establish content consistency only.
- Explicit geometry settings in newly exported replay records. Legacy standard-geometry records can be checked; a legacy custom-geometry seal without its original parameters fails with an explanatory message.
- Practice City Key projections retain the lattice map and existing κ profile but omit `packets` and `witness`, which older consumers may treat as chargeable. Practice completion cannot manufacture 42 units of proven focus.
- Territory picture-only export; previews of full replay PNGs and seal cards showing both metadata chunks; Flower full-plan preview; selected task readings with an explicit allowlist and no private history.
- Unrecognised top-level replay fields survive an accepted private replay import/export. This is not yet a general continuing-City-Key editor.
- Narrow-screen fixes, focus styles, keyboard orbit/zoom, motion pause and a 2D fallback when a 3D instrument cannot load.

## Compatibility boundaries

The 42-station geometry, bit mapping, game hash exclusions, City Key hash exclusions and existing fold calculation are retained. New practice metadata is outside the legacy group-seal calculation. A new City Key projection has a new fingerprint because its content deliberately changes; no old key is silently rewritten.

The stored task uses `game42.journey` within the existing versioned storage wrapper. Existing Flower/Map/Grid records remain in place. Revisions retain the prior task privately. Restore accepts only a full version-1 practice journey backup, never a selected reading.

Picture-only files contain no carrier chunks. Full game replay backups preserve the runtime’s event log; Map-only lighting is a separate planning view and is explicitly described as outside that replay. The task backup preserves the task and its private history. The selected reading is not advertised as a City Key accepted by Star consumers.
